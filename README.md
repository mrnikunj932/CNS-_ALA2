An interactive cybersecurity awareness website that demonstrates how viruses, worms, and trojans can affect computer systems.

🌐 **[Open Malware Awareness Lab](https://malware-awareness-lab.web.app)**

## Technologies Used
- HTML

- JavaScript

## Disclaimer
This project uses simulated animations for educational cybersecurity awareness. It does not infect real computers.
